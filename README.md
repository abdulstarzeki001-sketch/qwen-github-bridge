# Qwen GitHub Bridge

Arabic mobile-first interface for reviewing changes suggested by a local Qwen model in PocketPal and proposing them to GitHub through Cloudflare Workers.

## Setup

1. `npm install`
2. `npx wrangler login`
3. `npx wrangler secret put GITHUB_TOKEN` (fine-grained token: Contents read/write and Pull requests read/write, selected repositories)
4. `npx wrangler secret put APP_PASSWORD` (strong unique password)
5. `npm run deploy`

Never commit tokens or `.dev.vars`. For local development use `npx wrangler dev` with `.dev.vars`.

## Workflow

Enter password, choose repository and file, read original, paste replacement content generated by PocketPal, preview, explicitly approve, and create a review branch and Pull Request. Main is never merged automatically.

## Limitations

PocketPal local inference is NOT connected directly. Manual copy/paste only. Existing UTF-8 files up to 300KB, one file per PR. The preview is a simplified changed-block comparison; inspect the GitHub PR before merging. Use Cloudflare Access, rate limiting and repository allowlists for production deployment.
