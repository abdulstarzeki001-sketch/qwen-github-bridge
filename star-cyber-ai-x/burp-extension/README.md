# STAR BURP AI Extension

The backend endpoint is available at:

`POST /api/burp/analyze`

Planned Montoya API integration:

- Context menu: Send to STAR CYBER AI X
- Selected request/response forwarding
- Finding panel
- Scope selector
- Evidence bundle ID display
- Retest action
- Screenshot/evidence attachment
- HTTP history triage
- WebSocket analyzer
- JWT/session analysis

The starter does not automatically export all Burp traffic. The operator selects the request/response to analyze.
