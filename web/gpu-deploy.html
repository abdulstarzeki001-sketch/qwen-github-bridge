INDEPENDENT GPU / STAR NEXUS V6

شغّل عقل STAR على خادم GPU مستقل

صورة Docker نُشرت عبر GitHub Actions. اتبع إعداد RunPod لتشغيل النموذج فعلياً، ثم اختبر الاتصال قبل تفعيل مسار STAR الجديد. هذه الصفحة لا تنشئ Pod ولا تخصم أي رسوم.

فتح لوحة RunPod ↗إدارة GPU من GitHub ↗ ملفات التشغيل ↗
قبل التشغيل: تحتاج حساب RunPod مموّلاً وخادم NVIDIA متاحاً وتخزيناً دائماً. نجاح نشر صورة Docker لا يعني بدء خادم GPU. تحقّق من إتاحة الصورة للقراءة من RunPod في GitHub Container Registry.
STEP / 01

اختر صورة الحاوية

في إعداد Pod اختر Custom Image، واستعمل الصورة المنشورة، ثم افتح المنفذ 8080/http فقط. لا تفتح منفذ Ollama رقم 11434.

ghcr.io/abdulstarzeki001-sketch/star-independent-ai:latest

يفضّل استخدام وسم SHA الثابت من GitHub Actions للإنتاج. إن كانت الصورة خاصة، عدّل Visibility للحزمة أو أضف بيانات Registry آمنة في RunPod.

STEP / 02

اضبط أسرار ونماذج الخادم

أضف متغيرات Pod التالية ضمن إعداداته الخاصة. قيمة التوكن تختلف من مستخدم لآخر ويجب أن تطابق السر الموجود لاحقاً في Cloudflare.

STAR_BACKEND_TOKEN = [RANDOM 64-CHAR HEX]
STAR_MODEL = gpt-oss:20b
STAR_ALLOWED_MODELS = gpt-oss:20b,qwen2.5-coder:7b,IHA089/drana-infinity-3b:3b

اختر تخزيناً دائماً مركّباً على /workspace. القائمة أعلاه تحمّل ثلاثة نماذج، لذا تأكد من سعة القرص. يمكنك البدء بنموذج واحد لتقليل التكلفة.

STEP / 03

جهّز عنوان الاتصال

بعد إنشاء Pod اكتب معرّفه فقط. سنكوّن رابط RunPod القياسي محلياً في جهازك دون إرسال المعرّف لأي خدمة.

https://POD_ID-8080.proxy.runpod.net/chat/completions

STEP / 04

افحص الاستدلال الحقيقي

من الكمبيوتر أو Terminal الخادم بعد تنزيل مشروع STAR، تحقق أن البوابة ترفض الوصول غير المصرح وأن النموذج يُجيب فعلياً. لا تضع التوكن في سجل أوامر مشترك.

export STAR_RUNPOD_ENDPOINT="https://POD_ID-8080.proxy.runpod.net/chat/completions"
read -rs STAR_BACKEND_TOKEN; echo
export STAR_BACKEND_TOKEN
node scripts/verify-runpod.mjs

ظهور inference_checked: true يعني أن طلباً حقيقياً نجح، وليس فقط أن صورة Docker موجودة.

STEP / 05

اربط STAR بـ Cloudflare Pages

بعد نجاح الاختبار، أضف هذه القيم في إعدادات مشروع Pages. احفظ التوكن كـ Secret وليس نصاً عاماً، ثم أعد النشر.

STAR_AI_PROVIDER=selfhosted
STAR_SELFHOSTED_URL=https://POD_ID-8080.proxy.runpod.net/chat/completions
STAR_SELFHOSTED_MODEL=gpt-oss:20b
STAR_ALLOWED_MODELS=gpt-oss:20b,qwen2.5-coder:7b,IHA089/drana-infinity-3b:3b
STAR_SELFHOSTED_TOKEN=[SAME SERVER TOKEN]

ابقَ على مزود الذكاء الحالي حتى ينجح اختبارك. لتغيير Pod ID مستقبلاً، حدّث العنوان في Cloudflare.

STEP / 06

اختبر STAR من الآيفون والآيباد

بعد تسجيل الدخول للمالك جرّب فحص الاتصال من STAR. نجاح فحص البوابة يعني أنها متصلة، وبعدها جرّب محادثة حقيقية.
