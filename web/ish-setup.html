مساحة STAR على iSH

ثبّت نسخة مشروعنا على الآيباد، واجلب ملفات المستودعات الـ17 داخل مجلدات منفصلة بأرقام GitHub ثابتة، ثم افتح معاينة الواجهة في Safari.

مستودع STAR ↗حزمة المصادر على GitHub ↗
01 / PREPARE & CLONE

تثبيت ونسخ STAR

انسخ الأوامر إلى iSH. إذا كان المستودع موجوداً مسبقاً انتقل مباشرةً إلى خطوة التحديث.

apk update
apk add --no-cache git python3 curl ca-certificates openssh-client
cd ~
git clone --depth 1 https://github.com/abdulstarzeki001-sketch/qwen-github-bridge.git
cd qwen-github-bridge
sh scripts/ish/star.sh setup
sh scripts/ish/star.sh doctor
02 / REPO SOURCE IMPORT

جلب مصادر المستودعات

الافتراضي: 7 مستودعات أساسية مختبرة. خيار all يجلب الـ17 بدون تشغيل ملفاتها، وقد يحتاج مساحة أكبر.

sh scripts/ish/star.sh sources list
sh scripts/ish/star.sh sources core
sh scripts/ish/star.sh sources status

لجلب الكل: sh scripts/ish/star.sh sources all

03 / SAFARI PREVIEW

تشغيل واجهة الموقع

الخادم المحلي يعرض HTML وCSS وJavaScript فقط. المحادثة والنماذج الحقيقية تعمل على النسخة المنشورة.

sh scripts/ish/star.sh serve 8080
فتح localhost ↗
04 / REFRESH

تحديث الملفات بدون حذف

التحديث Fast-forward فقط، ولن يتجاوز تغييراتك المحلية. بعدها تستطيع تحميل أي مصدر محدد من جديد.

cd ~/qwen-github-bridge
sh scripts/ish/star.sh sync
sh scripts/ish/star.sh sources one drana
sh scripts/ish/star.sh doctor
فتح STAR السحابي ↗

تنبيه: iSH لا يشغّل GPU أو Docker أو Cloudflare Functions. الكود الخارجي محفوظ كمصادر للمراجعة، وليس كتطبيقات مثبّتة تلقائياً. لا تضف مفاتيح GitHub أو Telegram أو RunPod إلى ملفات الواجهة.
